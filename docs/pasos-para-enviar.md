# Pasos para enviar el concepto (RIE-03)

**Fecha límite: jueves 26 de noviembre, 11:59 p. m. (hora de Perú).** Un solo desafío por equipo. Mejor enviar con horas de margen.

## 1. Que el equipo lo revise y lo acuerde

Compartan `retos/RIE-03/entrega/formulario.md` y los 3 archivos de `retos/RIE-03/entrega/adjuntos/`. La plataforma pide declarar que la propuesta fue **revisada y acordada por todos**.

Si el equipo cambia de desafío, este paquete no sirve: avisen a Claude para preparar el otro.

## 2. Llenar el formulario

En https://cajathon.cajatrujillo.com.pe/equipos/ → **Concepto de solución** → **Comenzar Concept Solution**.

1. Desafío: pestaña **Riesgos** → **RIE-03**. Nombre: el de `formulario.md`.
2. Pasos 2 a 5: copiar cada bloque gris en su campo (ya están dentro de los límites).
3. En «Material visual» (paso 2): subir los 3 archivos de `adjuntos/`. Enlace complementario: dejar vacío.
4. Punto de partida: **Desarrollo a partir de soluciones o componentes preexistentes**, con el desarrollo indicado en `formulario.md`.
5. Datos e insumos: **No requerimos datos ni insumos**.
6. Usen **Guardar y salir** si quieren terminar más tarde.

## 3. Revisar y enviar

- Lean el resumen final campo por campo antes de enviar.
- Marquen las tres declaraciones (equipo de acuerdo, preexistentes con titularidad, desarrollo nuevo en el evento).
- Envíen y guarden una captura con la hora.
