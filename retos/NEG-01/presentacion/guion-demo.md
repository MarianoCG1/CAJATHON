# NEG-01 — guion de demostración (5 minutos)

Guion para la fase presencial, con el prototipo construido en el evento. Hoy es solo un guion: no hay prototipo.

| Minuto | Qué se muestra | Qué se dice |
|---|---|---|
| 0–0.7 | Dos negocios piden el mismo monto | Con cuota fija, cada uno sufre en meses distintos. |
| 0.7–1.7 | Mostrar el ciclo de cada uno | Patrón del sector y la zona, ajustado con lo observado, con su banda. |
| 1.7–2.8 | Ver el plan y el motivo de cada cuota | Cuota/UN bajo el factor en cada etapa. |
| 2.8–3.5 | El asesor baja el factor | El plan se recalcula; la decisión sigue siendo suya y del comité. |
| 3.5–4.4 | Comparar en un año adverso | Tensión, costo y TCEA frente a la cuota fija. |
| 4.4–5 | Banco de pruebas y hoja para comité | Resultados medidos sobre perfiles sintéticos. |

## Si algo falla en vivo

- Si falla el modelo de lenguaje: resumen por plantilla, sin red.
- Si falla la optimización completa: motor base de pago máximo por periodo.
- Si falla la interfaz: plan y comparación desde la API.
